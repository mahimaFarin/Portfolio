#  Personal Portfolio Website

## Project Overview

This is my personal portfolio website developed using **HTML5** and **CSS3**. The website showcases my educational background, technical skills, projects, achievements, and contact information in a clean and responsive design.

The goal of this project is to present my work, skills, and experience while practicing front-end web development and responsive web design.

---

## Key Features

- Responsive and modern user interface
- Home section with personal introduction
- About Me section
- Education section
- Skills section
- Projects section
- Achievements section
- Contact section
- Download CV button
- Contact form powered by FormSubmit
- Social media links

---

## Technologies Used

- HTML5
- CSS3
- FormSubmit
- Git
- GitHub
- Visual Studio Code

## Installation Guide

To run this project locally:

1. Clone the repository:

```bash
git clone https://github.com/mahimaFarin/Portfolio.git
```

2. Open the project folder.

3. Open the folder in **Visual Studio Code**.

4. Open **index.html** using a web browser or run it with the **Live Server** extension.

---

## How to Use

- Browse the different sections using the navigation bar.
- Learn about my education, skills, and projects.
- Download my CV using the **Download CV** button.
- Use the Contact section to send a message.
